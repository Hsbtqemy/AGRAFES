# T-03 — isoler les packs de tests versionnés

**Arrêté sur** — `git mv` des 11 packs versionnés sous `tests/contracts/`, commit `719ea6f`, 21 juin 2026.

## Contexte

**Aucun reliquat.** Le tracker porte `✅ corrigé` (P1-6).

Les fichiers nommés par incrément — des gels d'API par jalon — étaient mélangés aux
~50 tests par domaine : `test_v2`, `test_v21`, `test_sidecar_v03` à `v15`,
`test_sidecar_jobs_v05`, `test_sidecar_hardening_v141`. Ils sont désormais sous
`tests/contracts/`.

comme `tests/importers/` et `tests/services/`) : 225 tests collectés, `tests/conftest.py`
toujours appliqué. Seul ajustement nécessaire : `test_v21` avait un `FIXTURES_DIR` en
`.parent`, repointé `.parent.parent` pour retrouver `tests/fixtures/tei` depuis le
sous-dossier.

Vérifié à l'époque : `pytest --collect-only tests/contracts/` (225 collectés, zéro erreur
d'import), run de `test_v2` + `test_v21` (36 passés), `ruff check src tests`.
